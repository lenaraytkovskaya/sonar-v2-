ЗАДАЧА 4.1 — скоринг и топ контактов. Ветка: feat/task-4.1-scoring
Первым коммитом сохрани в docs/prompts/step-4.md краткое описание 4.1–4.2 и этот текст.

1. Скоринг (packages/core, чистая функция, тесты): балл 0–100 = взвешенная сумма признаков по весам кампании
   (campaigns.scoring_weights; сейчас ключи website/phone/rating — расширь набор признаков и значения по умолчанию
   в форме кампании, миграцией обнови пресеты):
   website (есть рабочий сайт, скан done), phone, email (на домене сайта — больше), messenger (telegram/whatsapp/viber),
   form, rating (рейтинг × log(кол-во отзывов), нормировать), registry (найден в ЄДР и не припинено),
   reachability (сколько разных каналов). Каждый признак 0–1, итог = Σ(w·x)/Σw·100.
   Разбивка (признак, значение, вес, вклад) сохраняется: таблица company_scores(company_id, campaign_id, score,
   breakdown jsonb, computed_at), unique(company_id, campaign_id).
2. Топ контактов по категориям (core): лучший email, телефон (мобильный выше для мессенджеров), мессенджер, форма,
   соцсеть — по rank, источнику (сайт/ЄДР/Google), свежести; результат в breakdown.top.
3. Пересчёт: задача company.score (идемпотентна по company_id+campaign_id+версия данных) — в конце конвейера
   обогащения (после registry.match, вместе с переходом в «Готова»), и при изменении весов кампании («Перерахувати»
   в кампании — пересчитать все компании кампании).
4. UI: «Компанії» — колонка «Скоринг» (число + полоска), сортировка по скорингу (по умолчанию для выбранной кампании),
   фильтр «скоринг від»; карточка — блок «Скоринг» вместо заглушки: число, разбивка по признакам, топ контактов
   по категориям с источником; CSV включает скоринг.
Тесты: формула, нормировка рейтинга, топ контактов, пересчёт при смене весов, сортировка/фильтр SQL.
