# Sonar: правила интерфейса

Образец — [shadcn/ui Blocks](https://ui.shadcn.com/blocks) (dashboard-01, settings). Цвета и шрифты — токены из
`docs/PLAN.md` §5 (`apps/web/src/app/globals.css`), их не меняем. Этот файл — про раскладку. Читать перед любой
задачей с интерфейсом.

## 1. Каркас страницы
- Меню слева на фоне `bg-background`; страница — на «листе» справа (`Shell`: скруглённая панель с рамкой).
- Верхняя строка листа: название раздела слева, меню пользователя справа.
- Контент: ширина не больше 1760px, отступы `px-8 py-7` (на телефоне `px-4 py-5`).
- Сверху страницы `PageHeader`: заголовок + одна строка описания. Главное действие страницы — справа в шапке.
- Между блоками страницы — `space-y-6`.

## 2. Блоки и вкладки
- Блок = `Section` (`components/ui/layout.tsx`): шапка (заголовок, одна строка описания, действия справа), под ней
  содержимое. Не вкладывать карточку в карточку: внутри блока строки — `rounded-lg border p-4` без тени.
- Вкладки — сегментами: дорожка `bg-chip p-1`, активная вкладка `tabActive` (белая с тенью), остальные `tab`.
- Списки однотипных объектов (компании, задачи, сервисы) — таблица; карточки — только когда у объекта картинка/много
  разнородных данных.

## 3. Кнопки
- На блок одна главная кнопка (`default`, акцент), рядом не больше одной-двух `outline`.
- Всё остальное — в меню ⋮ (`RowActions`): редактировать, включить/выключить, удалить (удаление — последним,
  красным, с подтверждением).
- Главная кнопка зависит от состояния: если нужно действие человека («Потрібен вхід»), она становится акцентной.
- Текст кнопки — глагол, 1–3 слова.

## 4. Данные
- Свойства объекта — `DetailList` («подпись → значение» сеткой 2–3 колонки), а не строки «Подпись: значение» столбиком.
- Статус — `StatusBadge` (точка + слово) рядом с названием объекта, цвета ok/run/wait/err/idle.
- Числа — `tabular-nums`, даты — `LocalTime`. Пустое значение — «—», строку без данных лучше скрыть.

## 5. Тексты и подсказки
- Под полем — подсказка в одну строку мелким серым. Длиннее — за значком ⓘ (`InfoTip`).
- Инструкции «как сделать» (cookies, ключи) — в `InfoTip` или раскрывающемся блоке, не на странице.
- Предупреждения и ошибки — `Callout` (wait / err), одно-два предложения, под объектом, к которому относятся.
- Размер текста: основной `text-sm` (14px), второстепенный `text-xs`, заголовок блока `text-base font-semibold`,
  заголовок страницы `text-2xl font-bold`. Серый (`text-muted-foreground`) — только для второстепенного.

## 6. Формы и диалоги
- Подпись над полем, поле во всю ширину, подсказка под полем. Связанные поля — в две колонки на широком экране.
- Внизу диалога: слева «Скасувати», справа главная кнопка.
- У полей с текстом — `AiAssist` (правило из AGENTS.md).

## 7. Проверка
- Смотреть страницу в светлой и тёмной теме и на ширине телефона (375px): нет горизонтальной прокрутки, кнопки не
  наезжают, всё читается.
