# Зміни

## 2.5.0 — 17.11.2026

- Відфільтровано контакти підрядників сайту й службові адреси соцмереж; нормалізовано посилання WhatsApp, Telegram і Viber.
- Додано контакти онлайн-запису, години роботи із сайту та локалізацію міста за кампанією.
- Відокремлено контактність від відповідності кампанії та оновлено пріоритет каналів.
- Додано автоматичний збір публічних профілів Instagram і Facebook через анонімні проксі; чернетки не створюються для кампаній із вимкненими каналами.
- Уточнено відповідність ЄДР-кодів із підвалу сайту; непевні збіги потребують ручного підтвердження.
- Чернетки запитуються у структурованому форматі та отримують причину відхилення без запису вмісту відповіді.
