# L5 — акаунти соцмереж

## Що зроблено

- Додав видалення акаунта з меню дій і підтвердженням українською. Видалення очищує облікові дані та сесію, знімає прив’язки повідомлень і діалогів, пропускає очікувані задачі та записує дію в `activity_log`.
- Додав у форму акаунта вкладки «Логін і пароль» та «Cookies». Створення через логін зберігає секрети зашифрованими й атомарно додає задачу входу.
- Додав integration- та API-тести, міграцію для безпечного обнулення прив’язки відправлених повідомлень.

## Як перевірити

- `pnpm lint && pnpm typecheck && pnpm test`
- DB-набір: `RUN_DB_TESTS=1 pnpm exec vitest run --maxWorkers=1` на тимчасовій БД.
- Docker dev-стенд: `COMPOSE_ENV_FILES=.env docker compose -f docker/compose.yml -f docker/compose.dev.yml up --build -d`; health: `http://localhost:58000/api/health`.
